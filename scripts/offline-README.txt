วิธีเปิดใช้งาน
  1. แตกไฟล์ zip นี้ไว้ที่ใดก็ได้ในเครื่อง (เช่น เดสก์ท็อป หรือ USB)
  2. ดับเบิลคลิกไฟล์ TTA-Leaderboard.html
     ควรเปิดด้วย Google Chrome หรือ Microsoft Edge รุ่นล่าสุด
     ถ้าเครื่องเปิดด้วยโปรแกรมอื่น ให้คลิกขวาที่ไฟล์ > Open with > Google Chrome
  3. กดปุ่ม F เพื่อแสดงผลเต็มจอ

ปุ่มลัด
  F   เปิด/ปิด โหมดเต็มจอ
  P   โหมดนำเสนอ (ซ่อนเคอร์เซอร์เมาส์)
  R   เล่นแอนิเมชันเปิดตัวอีกครั้ง

หมายเหตุ
  - ไม่ต้องใช้อินเทอร์เน็ต ฟอนต์และโลโก้ทั้งหมดรวมอยู่ในไฟล์เดียวนี้แล้ว
  - เวอร์ชันนี้แสดงข้อมูลตัวอย่าง การโหลดผลการแข่งขันจริงจาก CSV หรือ
    Google Sheet จะเพิ่มในเวอร์ชันถัดไป

How to open
  1. Unzip this file anywhere (desktop or USB stick).
  2. Double-click TTA-Leaderboard.html.
     Use a current Google Chrome or Microsoft Edge. If another program
     opens it, right-click the file > Open with > Google Chrome.
  3. Press F for fullscreen.

Shortcuts
  F   toggle fullscreen
  P   present mode (hides the mouse cursor)
  R   replay the entrance animation

Notes
  - No internet needed: fonts and logos are embedded in this one file.
  - This version shows sample standings. Loading real results from a CSV
    or Google Sheet comes in a later version.
